Install

One command. It builds a private virtualenv, installs JARVIS, and trains his intent router — all on your machine. Pick your OS; the copy button grabs the exact command.

macOS 12+

Cortex Terminal

Full feature set: voice, apps, files, vitals, stay-awake. Native voice via say.

curl -fsSL https://raw.githubusercontent.com/lfthkenzie-debug/JARVIS/main/install.sh | bash
Windows 10 / 11

Power Shell

Run from PowerShell. Voice via PowerShell synthesis; volume control needs NirCmd (optional).

powershell -c "irm https://raw.githubusercontent.com/lfthkenzie-debug/JARVIS/main/install.ps1 | iex"
Linux (deb / rpm)

Open Kernel

Systemd integration. Voice via espeak-ng or spd-say; volume via pactl.

curl -fsSL https://raw.githubusercontent.com/lfthkenzie-debug/JARVIS/main/install.sh | bash

Already have the code? macOS/Linux: ./install.sh  ·  Windows: double-click install.bat or run .\install.ps1. Needs Python 3.9+.

Local by design

Why a download, not a website?

  • JARVIS runs shell commands — volume, files, screenshots. A browser sandbox can't do that for you.
  • A hosted web page could only ever control the server's machine — someone else's laptop, and their secrets.
  • So JARVIS ships to your device: each person controls their own computer, and nothing is uploaded.
  • This page is the public distribution point — the assistant itself always runs beside you, offline.

Agentic & always-on

  • Say "keep yourself awake, Jarvis" — he holds a sleep assertion for the machine (caffeinate / SetThreadExecutionState / systemd-inhibit).
  • He won't doze off or quit until you tell him to "sleep" or "power down".
  • Launch with run.sh --ui / run.bat --ui to keep the panel and brain resident.
  • Full privacy: jarvis_data/ never uploads; UI binds 127.0.0.1 only, with a PRIVACY toggle for demos.
